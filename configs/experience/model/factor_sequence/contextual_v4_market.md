## 连续市场分支

使用现有 repaired `factormarket` 中的 `market_up`、全部八项 MarketDailyRisk
及各自的有效标记，共 18 个输入。这里的“连续市场”指每日状态分支，
`market_up` 本身仍然是 0/1：

- market_up：指数当日收益大于零，否则为零；源缺失仍无效。
- true_range、turnover、largebuy_price_deviation、smallbuy_percentage。
- sqrt_avg_size、open_close_percentage、5min_ret_volatility、5min_ret_skewness。

风险指标直接沿用数据块的过去 120 日、至少 60 个观测标准化和 ±5 裁剪，
不在网络里二次标准化，不新增滚动特征。无效值在输入编码时置零并保留有效标记，
不前向填充。至少一个市场观测有效才启用该分支；全部无效则输出严格为零。
未成熟的风险指标不会因为 market_up 可用而被当成真实零风险。

```
r_market = tanh(A_market @ market_features)   # 18 -> 2
u_market = B_market @ r_market                # 2 -> 33
```

两层均无偏置，A 正常随机初始化，B 零初始化。新增参数 18×2＋2×33＝102。
连续版虽然按现有合同读取完整 30 通道块，但事件的 12 个存储通道完全不进入网络；
测试覆盖任意修改事件通道均不影响连续版预测。

## 稀疏事件分支

使用三个既有事件：暴跌反弹 `selloff_rebound`、横盘突破 `platform_breakout`、
高位切换 `high_level_switch`。每种事件生成四个输入，共 12 维：

1. 当日触发 0/1；
2. 当日事件来源是否有效；
3. 最近事件的衰减强度 `exp(-age/20)`；
4. 事件年龄是否有效。

年龄从现有 `log1p(min(age,252))/log1p(252)` 通道解码，不重算事件定义。
首次事件前年龄未知，衰减编码为零且有效性为零；不能把未知解释为刚发生。
事件源无效时对应年龄也不使用。三个事件同日触发分别保留。
当年龄通道达到封顶值 1（至少 252 日）时，衰减明确置零，避免固定尾部永不消失。
这是有限影响窗口的建模规则，不代表恢复了超过 252 日的真实年龄。

```
r_event = tanh(A_event @ event_features)      # 12 -> 1
u_event = intensity * B_event @ r_event       # 1 -> 33
intensity = max(三个事件的触发标记与衰减强度)
```

两层无偏置，末层零初始化；新增参数 12×1＋1×33＝45。
乘 intensity 使有效性标记本身不会产生不衰减的固定尾部；没有已知当前/近期事件时，
整个事件响应严格为零。20 日是 e-fold 衰减常数，不是半衰期，亦不是按标签拟合的最优期限。
连续触发会按既有事件年龄合同刷新年龄，不能视为新增独立事件样本。

## 合并、缺失与正则化

```
u = u_performance + u_market [+ u_event]
gate = 1 + 0.2 * tanh(u)
score = temporal_score + sum_f(w_f * value_f * (gate_f - 1))
```

只在合并后施加一次 tanh，总门控仍在 [0.8,1.2]，不连乘放大。
所有分支都只调节当前线性因子贡献，不改股票 GRU、不直接加公共市场预测分数。
市场 2 维表示对应两种跨因子响应方向，事件只有一种；这是主动限制表达能力，
不是假定已经捕获所有市场/事件作用。

表现、市场、事件分别判定可用性：某因子表现不足 20 个有效观测，仅关闭其表现项；
市场仍可调节它。连续市场缺失也不关闭有效事件。所有情境失效时返回 Temporal 路径。
股票因子当前无效时不产生任何情境修正，样本筛选不变。

沿用 `loss_context_shrinkage`，系数 0.01：合并门控偏离 1 的均方惩罚，
再加新增市场/事件分支各自 `mean((0.2*tanh(u_branch))²)`，降低分支相互抵消
而形成大响应的空间。原始纯 v4 不增加这些分支惩罚，其预测与参数键保持兼容。
新增层末端零初始化时，扩展版与相同已加载股票/表现/市场权重的父版本预测一致。

forward 保留原来的 hidden、线性/残差分数、总门控和修正分数；新增
performance_logits/performance_ready、market_logits/market_features/market_ready，
事件版再返回 event_logits/event_features/event_ready。gate_ready 表示任一情境可用。
这些额外张量用于诊断调用，当前普通回调不额外持久化逐日门控张量。

## 参数量与计算复杂度

默认 33 因子、32 隐藏维度、两层股票 GRU：

- Temporal：22,275 参数。
- 纯 v4：22,404；情境部分 129。
- v4 连续市场：22,506；情境部分 231，相比纯 v4 增加 102（约 0.46%）。
- v4 连续＋事件：22,551；情境部分 276，相比纯 v4 增加 147（约 0.66%）。
- 旧 v3 Contextual：48,515；两个新变体总参数均减少约 53.5%。

各版本股票主干成本相同，仍主要由 N 只股票、L=60 日的投影和双层 GRU 决定：
`O(N * L * (Dx*H + H²))`，其中 Dx=132、H=32。主干矩阵乘加约每股 996,033 次，
未计偏置、激活、逐元素门运算和反向传播。

v4 的公共表现摘要为 `O(T * F * S)`（T=120、F=33、S=3），只计算一次。
连续市场的两个线性映射额外 102 次乘加，事件分支再额外 45 次；
这些是每个单日期 batch 的公共计算，**不乘股票数，也不沿 120 日运行 GRU**。
总门控应用仍为 O(N*F)，与纯 v4 相同。完整运行耗时不能仅按这些乘加数推断。

股票回看 60 日、表现回看 120 日；新增市场流仅取当日 1 日，形状 `[1,1,30]`。
事件历史已通过数据块年龄通道携带。读取时保留公共股票轴为 1，不复制到全部股票。
全部底层数据块仍由既有加载器管理；小网络不能消除股票数据与训练激活的主要内存开销。
